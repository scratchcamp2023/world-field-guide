# Contributing to World Field Guide

Thank you for helping build a community-powered GeoGuessr learning resource.

World Field Guide is not trying to collect unverified trivia. We want useful, well-scoped visual evidence that helps players make better geographic decisions.

## Ways to contribute

You do not need to be a developer.

- **Suggest a clue:** Open a GitHub issue and describe the country or region, the visible feature, and why it matters.
- **Share an example:** Include a Street View link or an image you have permission to share. Add the location/context and explain what the example demonstrates.
- **Improve a guide:** Suggest corrections, missing exceptions, clearer wording, or useful comparisons.
- **Improve the website:** Submit a pull request for code, accessibility, usability, or documentation changes.

## Before submitting a clue

Please include as much of the following as possible:

1. **Location and scope** — country, state/province, region, road type, or coverage type.
2. **Clue family** — infrastructure, road markings, vehicles, coverage, architecture, landscape, language, or other.
3. **Observation** — describe exactly what is visible. Avoid conclusions that go beyond the evidence.
4. **Usefulness** — explain what the clue can help distinguish.
5. **Exceptions and false friends** — where might the same feature appear, or where might it mislead a player?
6. **Evidence** — provide multiple examples or reliable sources where possible.
7. **Image rights** — state who created the image and its licence or permission basis.

## Evidence and image policy

- Never upload images you do not own or have permission to redistribute.
- A public Street View URL can be useful as a reference, but it does not automatically grant permission to download and republish the imagery.
- Do not present a single anecdotal example as a universal rule.
- Distinguish verified claims from hypotheses and observations still under review.
- Explain uncertainty. A useful clue with clear limitations is better than an overconfident claim.

## Review process

Contributions may move through these states:

1. **Draft** — received, not yet reviewed.
2. **In review** — scope, repeatability, evidence, and possible confusions are being checked.
3. **Verified** — evidence supports the claim within a clearly stated scope.
4. **Deprecated** — the claim is outdated or no longer reliable.

Submitting a contribution does not guarantee publication. Reviewers may ask for clarification, narrow the claim, or decline material that cannot be verified.

## How to submit

Open a [new issue](https://github.com/scratchcamp2023/world-field-guide/issues/new) for a clue suggestion, correction, or discussion. For code or documentation changes, fork the repository and submit a pull request.

Please keep discussions constructive and focus criticism on the evidence and the claim, not the contributor.

Thank you for helping make GeoGuessr knowledge more open, careful, and useful.

## Languages

You may submit an issue or evidence in any language. The project is currently English-first, so maintainers or volunteers may translate or ask for clarification before publication. Please keep original-language text or a translation note when it is important to interpret a sign, road marking, or local term.
